# /rdl:make — 美容室の動画をつくる

使う人は美容師さん。**専門用語を使わず、選ぶだけで進める。** 質問は AskUserQuestion の選択式で、1回に多くても3問。おすすめを1番目に置き「（おすすめ）」と書く。

エンジン：`ENGINE = <このスキルのフォルダ>/../../engine/rdl.py`。Python は Windows なら `python`、それ以外は `python3`。

## 0. 最初の1回だけ：道具の確認
`python ENGINE env` を実行。`"ready": true` でなければ `/rdl:setup` に切り替えて、そろえてから戻る。

## 1. 何を作るか（選択式）
**Q1 どんな動画？**
- **Style（髪を見せる）**：ビフォーアフター／スタイル紹介（前・横・後ろ）／施術の流れ
- **Brand（お店を伝える）**：新メニュー告知／求人／お客様の声／爆速カット
- **Talk（話す）**：語り／立体テロップ／ノウハウ解説

**Q2 演出はおすすめでいい？** →「おすすめで（おすすめ）」なら `order.md` の「おすすめ表」をそのまま使う。「自分で選ぶ」なら、文字の出方・切り替えを**それぞれ3つまで**、フォント（大きい文字／テロップ）、配色（見本6種 or 好きな3色）、テンポ、長さ（15/30/60秒）、サイズ（9:16／4:5／1:1）を聞く。どれも `order.md` に一覧がある。

## 2. 素材と言葉をもらう
種類ごとに要る物（`order.md` の「素材」）を、例をつけて頼む。写真はチャットに貼ってもらうか、フォルダの場所を教えてもらう。
- 言葉は**短く**。一言（copy）は15文字前後。長い時は自分から2案に縮めて選んでもらう。改行したい所は `\n`
- Talk は**話した内容の文章（台本）**をもらう。Claude は音声を聞けないので、文字起こしはできないと先に伝える。台本が無ければテロップなしで作れる
- サロン名と締めの一言（例「ご予約はプロフィールから」）

## 3. 出す前の安心チェック（必ず）
`salon.md` の「安心チェック」を通す。引っかかったら言い換え案を出して選んでもらう。お客様の顔が写っていれば、掲載の許可を取ったか必ず聞く。

## 4. 作る
1. 作業フォルダ `rdl-work/<日付>_<名前>/` を作り、素材をコピーし、`order.json` を書く（書き方＝`order.md`）
2. **絵コンテ**：`python ENGINE board order.json` → `out/board.jpg` を見せて「この流れでいいですか？」。直しは order.json を変えて出し直す
3. OK なら **書き出し**：`python ENGINE make order.json`（試しは `--preview` で半分の画質・速い）。15秒で2〜5分かかると先に伝える
4. **監督の確認**：`/rdl:check` の手順で見る（`python ENGINE check <mp4>`）。直す所があれば直してから渡す
5. 渡す：できたファイルの場所と、`salon.md` の書き方で **投稿文の下書き＋ハッシュタグ**を添える

## 決まり
- 動画の質の基準は `/rdl:check` が上。迷ったら「統一感・引き算」
- 写真は髪や顔を枠で切らない（Style は全体を入れて余白をぼかす作りになっている）
- 下 420px と左右 60px に大事な文字を置かない（インスタの表示で隠れる）
- エンジンのコードを書き換える前に、order.json の設定で直せないか先に考える
