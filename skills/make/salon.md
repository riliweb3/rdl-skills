# 美容室のための決まり（安心チェック・撮り方・投稿文・言葉の辞書）

## 1. 安心チェック（出す前に必ず）
目安であって、法律の判断ではない。迷う時はメーカーや専門家に確認してもらう。

**避けたい言い方 → 言い換え**
| 避けたい | 理由の目安 | 言い換え |
|---|---|---|
| 髪が修復する・治る・再生する | 薬や治療のような効き目に聞こえる | 手ざわりが変わる・まとまりやすくなる |
| 絶対／必ず／100% | 言い切りすぎ | 〜を目指します・多くの方が〜 |
| ダメージゼロ・傷まない | 言い切りすぎ | ダメージを抑えた |
| 育毛・発毛・薄毛が治る | 医薬品のような表現 | 頭皮をすっきり整える |
| 白髪が生えなくなる | 効き目の言いすぎ | 白髪をなじませる |
| No.1・日本一（根拠なし） | 比べる根拠が要る | 当店で人気の |
| 今だけ（ずっとやっている） | 期間の言い方に注意 | 3月31日まで など日付を書く |

**写真・動画**
- お客様の顔や体が写っていたら「掲載の許可（できれば文字で残る形）を取りましたか？」と聞く。取れていなければ、顔が写らない写真に替えるか、後ろ姿にする
- 他店・他人の写真、雑誌やネットの画像は使わない
- 曲：自分で作った物・使ってよい物だけ。インスタで流行りの曲を使いたい時は、**音なしで書き出して、インスタの投稿画面で曲をつける**（`"music"` を書かない）

## 2. 撮り方のコツ（素材の質で仕上がりが決まる）
- **明るい所で**：窓の光が顔と髪に当たる向き。逆光は暗くなる
- **ピントを固定**：iPhone は画面の髪の所を長押し（AE/AFロック）。撮ったら拡大して確認
- **縦で撮る**・レンズを服で一拭き
- 背景は片付けて無地寄りに。鏡越しなら自分が写り込まない角度
- ビフォーアフターは**同じ場所・同じ角度・同じ明るさ**で撮る（差が髪だけになる）
- スタイル紹介は前・横・後ろを同じ距離で。後ろは襟足まで入れる
- 自撮りで話す時：目線はレンズ、最初の一言は大きめに、言い直しは一度止まってから言い直す（無音が入るので自動で削れる）

## 3. 投稿文の下書き（動画と一緒に渡す）
```
（1行目：止まる一言。動画の copy と同じか、問いかけ）
（2〜3行：どんな人に向くか・何が変わるか）
（メニュー名・時間・価格・期間）
ご予約はプロフィールのリンクから
#〇〇市美容室 #〇〇駅美容室 #（メニュー名） #（髪の悩み） #（髪型の名前）
```
- ハッシュタグは5〜10個。**地名＋美容室**を必ず入れる（近くの人に届く）
- 4:5 は投稿（フィード）、1:1 は Google ビジネスプロフィールの写真・投稿に使えると伝える

## 4. 言葉の辞書（音声入力で化けやすい美容の言葉）
台本や言葉に、意味の通らない漢字が出てきたら、ここで読み替えてから使う。読み替えたら一言伝える。
| 化けやすい | 正しくは |
|---|---|
| 縮毛強制・宿毛 | 縮毛矯正 |
| 白種・プリーチ | ブリーチ |
| インナー空ー | インナーカラー |
| 霊屋・レイや | レイヤー |
| 外跳ね・外羽 | 外ハネ |
| 前が身 | 前髪 |
| 髪質回線 | 髪質改善 |
| 鳥と面と | トリートメント |
| 襟もし | 襟足 |
| ハイトーン・灰と0 | ハイトーン |
| 刈り上げ・借り上げ | 刈り上げ |
