# /rdl:check — 監督の確認

作ったままでは「いい場面と悪い場面の差」「全体のばらばら」が残る。**見せる前に、監督として通しで見て直す。**

`ENGINE = <このスキルのフォルダ>/../../engine/rdl.py`

## 1. 測る
`python ENGINE check <動画.mp4>` → `_sheet.jpg`（0.5秒ごとのコマ一覧）を**自分の目で見る**。`notes` に出た物は直す候補。
- 止まって見える所：意図した「一瞬の静」（0.3〜0.6秒）でなければ直す
- 真っ黒が続く所：暗転のつもりでなければ詰める
- 音量：-11 LUFS 前後（声が割れない範囲で大きめ）・ピーク -1 dB 以下。書き出しで自動でそろえる（2回に分けて測る）

## 2. いちばん上の決まり：統一感と引き算
- 色は3つまで・質感は2つまで・字体は2つまで
- 演出は**引き出し**。毎回全部入れない（文字の出方・切り替えはそれぞれ3つまで）
- 動きの決まり（入り・出・止まり）を全場面でそろえる。入りは「一気に動いてピタッと止まる」、等速は使わない
- 最後に**引き算を1回**：外しても困らない物は外す
- 直したら、前の版と並べて比べる。良くなっていなければ渡さない

## 3. チェック表（1つでも外れたら直す）
- [ ] **0コマ目が絵になっている**（入りかけの文字で始まらない）。最初の1秒で何の動画か分かる
- [ ] **髪が主役**：髪や顔が枠で切れていない／1場面の主役が画面の6〜8割
- [ ] **読める**：一言は0.6秒以上止まっている（1文節0.3秒＋0.5秒が目安）／スマホの大きさで読める
- [ ] **同じ色の上に同じ色を置いていない**（赤の上に赤など）／暗すぎて読めない場面がない／テロップが髪や顔を隠していない
- [ ] 下 420px・左右 60px に大事な文字がない
- [ ] 切り替えの**途中のコマ**で文字と文字が重なっていない
- [ ] カメラの動き（寄り・引き・回り込み・左右）が2種類以上ある。**覚えてもらう見せ場が1つ**ある
- [ ] 締め（サロン名と一言）が1.5秒以上読める
- [ ] 音：見せ場の音が埋もれていない／最後は1秒ほどでフェードアウト
- [ ] 安心チェック（`../make/salon.md` §1）を通っている

## 4. 直し方
- 直す時は**秒と、変える値**で書く（例「3.2秒の一言を0.4秒長く」→ length や tempo、文字を短くする）
- 1回に直すのは1〜2点。直したら `board` か `--preview` で**その部分をもう一度見る**。見ていない直しを「直した」と言わない
- 止める時：チェック表が全部通った／残りが細かすぎる／本人が止めた。直しの往復は最大5回、良くならなければ相談する
